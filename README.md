## Overview

pyWebs is a small Minecraft plugin made for BoxPvP servers.

It adds custom cobweb items that automatically despawn after a configured amount of time.  
Useful if you want cobwebs in PvP, but do not want the arena filled with webs forever.

## Features

- Custom cobweb tiers
- Configurable despawn timers
- Custom item names and lore
- Optional progress display above webs
- Disabled worlds support
- Optional firework blocking while inside cobwebs
- Toggleable placement message
- Hex color support for messages
- Optional bStats support
- Single optimized task for all active webs

## Commands

```txt
/pywebs
/pywebs cobweb give <player> <nbt-key> [amount]
